# Employee Salary Management System

A Java Swing application to manage employee salaries, calculate monthly totals, personal totals, and identify the highest salary.

## Overview
The Employee Salary Management System allows users to add employee records, input monthly salaries, calculate totals, update salaries above a certain threshold, and find the maximum salary. The intuitive GUI provides easy management of salary data.

## Features
- Add new employees and their monthly salaries.
- Calculate total salary per month.
- Calculate total salary per employee.
- Update salaries above a specified value.
- Identify the highest salary among all employees.
- User-friendly GUI built with Java Swing.

## Technologies
- Java 8+
- Java Swing for GUI
- Object-Oriented Programming (OOP)
